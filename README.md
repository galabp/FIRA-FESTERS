# Caixa registradora — Festers Joves Ròtova

## Obrir l'aplicació
1. Descarrega i descomprimeix el ZIP.
2. Obri Visual Studio Code i ves a **Fitxer → Obrir carpeta**.
3. Tria la carpeta `caja_bebidas_tapas`.
4. Obri `index.html`. Recomanat: instal·la l'extensió **Live Server** i prem **Go Live**.
5. La caixa s'obrirà al navegador.

## Funcionament
Selecciona articles, ajusta quantitats, introdueix els diners rebuts, comprova el canvi i confirma el cobrament. Al final, prem **Exportar vendes (CSV)**.

Les vendes es guarden en el navegador i en l'ordinador on s'ha utilitzat l'aplicació. Exporta-les al final; no es sincronitzen entre dispositius ni és un programa de facturació fiscal.
